# Замер скорости скачивания (CLI)

Консольный скрипт на Node.js для оценки скорости скачивания файла по HTTP/HTTPS.

Скрипт выполняет **10 последовательных GET-запросов** к указанному адресу, дожидается полной загрузки тела ответа на каждый запрос, после чего выводит среднее время запроса, общий объём загруженных данных и итоговую скорость скачивания.

## Требования

* **Node.js 18.0 или выше** (используются встроенные `fetch` и `node:perf_hooks`, установка сторонних пакетов не требуется).

## Установка и запуск

1. Склонируйте репозиторий и перейдите в директорию проекта:

   ```bash
   git clone git@github.com:AVP-Dev/http-download-benchmark.git
   cd http-download-benchmark
   ```

2. Запустите скрипт, передав первым аргументом прямую ссылку на файл (для объективной оценки пропускной способности лучше использовать файл от 5–10 МиБ):

   ```bash
   node measure.mjs https://example.com/large-image.jpg
   ```

   > Если в URL содержатся спецсимволы (например, `&`), возьмите ссылку в кавычки:
   >
   > ```bash
   > node measure.mjs "https://example.com/file.bin?size=10m&raw=1"
   > ```

## Пример вывода

```text
Запуск замера скорости (10 последовательных запросов)...
URL: https://example.com/large-image.jpg

[1/10] 2.45 МиБ за 412 мс
[2/10] 2.45 МиБ за 389 мс
...
[10/10] 2.45 МиБ за 401 мс

--- Результаты ---
Выполнено запросов: 10
Общий объём данных: 24.50 МиБ (25690112 байт)
Среднее время запроса: 398.40 мс
Средняя скорость скачивания: 6.15 МиБ/с (51.59 Мбит/с)
```

## Единицы измерения и методика расчёта

* **МиБ (мебибайт)** — двоичный мегабайт (`1 МиБ = 1024 × 1024 = 1 048 576 байт`).
* **МиБ/с** — мебибайты в секунду: отношение общего объёма скачанных данных (в МиБ) к суммарному времени всех 10 запросов (в секундах).
* **Мбит/с** — мегабиты в секунду (`1 Мбит = 1 000 000 бит`), стандартная сетевая единица измерения пропускной способности канала.
* **Кэширование**: используется параметр Fetch API `cache: "no-store"`, чтобы локальный кэш клиента не искажал замеры, при этом исходный URL передаётся без изменений (безопасно для подписанных ссылок).
